# Symfony

Приложение на Symfony для продажи цифровых товаров с интеграцией с Робокассой.

Для создания окружения Docker используется:
[https://github.com/dunglas/symfony-docker](https://github.com/dunglas/symfony-docker)

## Для запуска проекта

1. git clone репозитория
2. `docker compose build --pull --no-cache`
3. `docker compose up --wait`
4. Открыть [https://localhost](https://localhost)
